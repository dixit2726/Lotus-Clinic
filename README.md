# Lotus Dental & Facial Aesthetic Clinic

A premium, luxury dental and facial aesthetic clinic website built with modern web technologies.

## 🚀 Technologies Used

- **React 18**
- **Vite**
- **Tailwind CSS v4** (with @tailwindcss/postcss)
- **Framer Motion** (for cinematic animations)
- **Lucide React** (for premium icons)
- **React Router** (for multi-page navigation)

## ✨ Features

- **Luxury Design**: Elegant burgundy and rose gold theme with glassmorphism effects.
- **Cinematic Animations**: Smooth, high-end transitions using Framer Motion.
- **Multi-Page Navigation**: Dedicated pages for Services, Offers, Testimonials, and Contact.
- **Interactive Booking**: User-friendly appointment request form.
- **WhatsApp Integration**: Floating WhatsApp button for instant communication.
- **SEO Optimized**: Local business schema and optimized metadata for Hyderabad dental clinic visibility.
- **Fully Responsive**: Perfectly optimized for all screen sizes.

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/lotus-dental.git
   ```

2. Navigate to the project directory:
   ```bash
   cd lotus-dental
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
